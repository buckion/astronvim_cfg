# Features

**NB:** Built with [AstroNvim](https://github.com/AstroNvim/AstroNvim)
All the goodies of VSCode without VSCode

## Instructions

#### 1. Backup or delete nvim caches

```shell
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

#### 2. Clone this repo

```shell
git clone git@github.com:buckion/astronvim_cfg.git ~/.config/nvim
```

#### 3. Start Neovim

```shell
nvim
```
